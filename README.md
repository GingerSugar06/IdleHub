# Idle Hub

Make Steam show the games you choose as "in-game" so their hours keep counting — for the account signed in on
**this PC**, and for **other accounts** over the network (no Steam client needed). Flutter desktop app for Windows.

🇹🇷 *Seçtiğin oyunları Steam'de "oyunda" gösterip saatlerini kasan Windows uygulaması. Bu bilgisayardaki hesap için
Python gerekmez; başka hesaplar için küçük bir Python motoru kullanılır. Arayüz Türkçe ve İngilizce.*

## Features

- **This PC** mode: pick games, press **Idle** — each game runs in its own tiny worker process. No Python, no game files needed
- **Other accounts** (QR code or username/password + Steam Guard) idle without the Steam client; sessions resume after restart
- Library with covers: installed games from your Steam folders, your full library with an optional free Web API key, custom games by AppID
- Search, favorites, "Idling" tab, per-game live timers, up to 32 games per account (Steam's limit)
- Tray icon, close-to-tray, launch with Windows, start minimized, TR / EN

## Security & privacy

- Passwords are sent only to Steam, kept in memory during sign-in and **never written to disk**
- Session keys (refresh tokens) and the Web API key are stored in **Windows Credential Manager**, not in files
- `state.json` (account names, favorites) lives in your user profile, never inside the repository
- The Python engine's log contains no secrets

## Build

Requirements: Flutter (Windows desktop), Visual Studio C++ workload. For "other accounts": Python 3.9+ (the app can install
the packages for you from *Settings → Network engine*).

```powershell
flutter pub get
powershell -File tool/build.ps1     # builds worker + app, copies engine/ → build\windows\x64\runner\Release\
```

For development: `dart compile exe` the worker once (`cd worker; dart compile exe bin/idle_worker.dart -o ../build/idle_worker.exe`)
and `flutter run -d windows`.

## How it works

| Piece | What it does |
|---|---|
| `worker/` (Dart, FFI) | Loads Steam's `steamclient64.dll`, opens a pipe with `SteamAppId=<id>`; Steam then tracks the process as that app |
| `lib/engine/this_pc.dart` | Keeps one worker per wanted game, restarts them when Steam comes back |
| `engine/engine.py` (Python) | Logs in through Steam's authentication service and sends `games_played`; JSON lines over stdin/stdout |
| `lib/engine/remote_account.dart` | Talks to the engine; tokens go to the secure store |

## Installer (setup wizard)

`powershell -ExecutionPolicy Bypass -File tool\make_installer.ps1` builds the app and an Inno Setup wizard:
`installer\Output\IdleHub-Setup-2.0.0.exe` (TR / EN, per-user install, no admin rights, Start-menu + optional desktop shortcut,
clean uninstall). The wizard offers (checked by default) to install **Python 3.12 and the engine packages** — needed only for adding other accounts. It warns if Steam is not installed.
Needs [Inno Setup 6](https://jrsoftware.org/isinfo.php) (`winget install JRSoftware.InnoSetup`). The app icon is generated by `tool/make_icon.py` (Pillow).
